Media Queries são fundamentais para design responsivo, pois permite aplicar estilos diferentes baseados nas características do dispositivo, como largura,/altura da tela, orientação ou resolução. Dessa forma altera o layout sem alterar o conteúdo, garantindo uma experiência ideal em desktop, tablets e celulares.

Site com versão para impressora

criar dois arquivos de css um para pagina web e outro apenas para impressoras, isso permite retirar ou colocar partes importante para cada uma das opções desejada, por exemplo para impressão do site não é necessario o menu já que não será possivel acessa-lo, logo no style de impressora não ele não precisa aparecer.
